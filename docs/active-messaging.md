# 如何允许 Bot 主动在群聊内发消息

当定时提醒、公告推送、状态通知等功能需要在**没有群成员先发送指令或 @Bot** 的情况下发消息时，需要先在 QQ 群内允许机器人主动发言。

::: warning 先区分两个设置
截图中的两个权限不是一回事：

- **机器人可获取的群聊消息范围**：决定 Bot 能读取哪些群消息。
- **机器人主动在群聊内发言**：决定 Bot 能否在没有成员先触发它的情况下主动向群里发送消息。

如果只是解决“Bot 不能主动推送”的问题，关键是第二个开关。  
如果还需要使用群聊分析、非 @ 指令、上下文处理等功能，则通常还需要把第一项设为“获取群内全部消息”。
:::

## 操作前确认

1. **Amia_晓山瑞希已经加入目标 QQ 群。**
2. 请使用**群主或具有机器人管理权限的管理员账号**操作。
3. 如果页面中的设置不可修改，优先让群主进入机器人设置确认。

## 详细开启步骤

### 第 1 步：进入目标群设置

打开 QQ，进入已经添加 **Amia_晓山瑞希** 的目标群聊，然后进入群设置页面。

不同 QQ 版本的入口名称可能略有差异，通常可以在群资料或群管理页面中找到 **机器人 / 群机器人 / 机器人管理**。

### 第 2 步：打开 Amia_晓山瑞希的机器人设置

在机器人列表中找到 **Amia_晓山瑞希**，进入它的设置页面。

你应当能看到类似下面截图中的选项：

![QQ 群机器人主动发言权限设置示例](/Picture/bot-active-message-settings.jpg)

图中橙色箭头标出了需要重点检查的两个位置。

### 第 3 步：设置“机器人可获取的群聊消息范围”

点击：

> **机器人可获取的群聊消息范围**

如果希望 Amia_晓山瑞希 能正常处理群内普通消息、非 @ 指令、群聊分析等功能，选择：

> **获取群内全部消息**

截图中蓝色勾选项就是正确状态。

::: info 这一项不是“主动发言”的发送权限
即使没有开启“获取群内全部消息”，理论上也不等于 Bot 一定不能主动发送消息。  
它控制的是 **Bot 能收到什么消息**，不是 Bot 能不能主动向群里发消息。
:::

### 第 4 步：开启“机器人主动在群聊内发言”

返回机器人设置主页面，找到：

> **机器人主动在群聊内发言**

将右侧开关打开。

正常情况下，开关开启后会显示为蓝色，和截图中的状态一致。

这个开关才是允许 Bot 执行**定时推送、主动通知、公告发送等非被动回复行为**的关键权限。

### 第 5 步：返回后再次确认

开启完成后返回上一层页面，再重新进入机器人设置确认一次：

- “机器人主动在群聊内发言”仍然保持开启；
- 如业务需要，“机器人可获取的群聊消息范围”为“获取群内全部消息”。

如果开关自动恢复为关闭状态，说明设置可能没有成功保存，或者当前账号没有足够权限。

## 开启以后为什么 Bot 还是不主动说话？

这里有一个容易误解的地方：

**开启这个权限，只是允许 Bot 主动发消息，不会让 Bot 自动产生消息。**

Amia_晓山瑞希 服务器端还必须真的存在一个主动发送逻辑，例如：

- 定时任务到点后发送消息；
- 服务状态发生变化后推送通知；
- 管理员触发公告推送；
- 某个插件在满足条件后主动发送内容。

如果当前没有任何主动推送任务正在执行，那么即使权限已经开启，Bot 保持安静也是正常的。

同样，发送“帮助”等普通指令只能证明 Bot 可以**回复消息**，不能证明“主动发言”权限一定可用。要验证主动发言，需要使用一个实际会主动发送消息的功能进行测试。

## 常见问题

### 找不到“机器人主动在群聊内发言”

先确认：

1. 进入的是 **群内机器人的设置页**，而不是普通群成员资料页；
2. 当前账号具有机器人管理权限；
3. QQ 客户端已经更新到较新的版本。

QQ 不同版本的菜单名称和位置可能会调整，但需要寻找的权限名称仍是与“机器人主动发言”含义相同的项目。

### 已经打开，但仍然收不到主动推送

按下面顺序检查：

1. Bot 当前是否在线；
2. 目标群是否仍然添加了 Amia_晓山瑞希；
3. “机器人主动在群聊内发言”是否仍然开启；
4. 对应插件或定时任务是否真的配置了这个群；
5. 后端是否出现发送失败、权限不足或平台接口错误日志；
6. 当前功能是否本来就只支持被动回复，而不支持主动推送。

### Bot 只能在被 @ 后工作

这通常与“主动发言”不是同一个问题。

如果某些功能需要读取普通群消息，请检查：

> **机器人可获取的群聊消息范围 → 获取群内全部消息**

同时还需要确认对应插件本身支持非 @ 触发。

## 推荐配置

对于需要完整使用 Amia_晓山瑞希 群聊能力的群，建议配置为：

| 设置 | 推荐状态 | 作用 |
| --- | --- | --- |
| 机器人可获取的群聊消息范围 | 获取群内全部消息 | 允许处理普通群消息、非 @ 指令及需要上下文的功能 |
| 机器人主动在群聊内发言 | 开启 | 允许定时推送、公告、状态通知等主动发送 |
| 机器人管理权限 | 由群主/管理员维护 | 用于后续修改机器人权限 |

如果群内只需要最基础的 @Bot 交互，可以按实际需求缩小消息读取范围，不必为了“主动发言”而无条件开放全部消息读取权限。

---

如果 Bot 权限已经按本页设置，但主动发送仍然失败，请在反馈时同时提供：**群号、触发的功能名称、发生时间、Bot 是否在线，以及后端对应时间段的错误日志**。这样更容易区分是 QQ 群权限、插件配置还是发送接口的问题。
