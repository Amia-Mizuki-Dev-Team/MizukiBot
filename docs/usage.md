# 如何使用 Amia_晓山瑞希

本页介绍邀请 Bot、配置群消息权限和触发常用指令的基本流程。

<div class="amia-guide-meta">
  <span>预计完成时间：5–10 分钟</span>
  <span>需要群主或管理员权限</span>
  <span>适用于 QQ 官方 Bot</span>
</div>

<DocCallout title="开始前准备">
请先确认目标群允许添加机器人，并准备由群主开启“获取群内全部消息”权限。服务状态、维护安排和临时限制以服务公告为准。
</DocCallout>

  </section>

  <section class="amia-step-card">
    <span class="amia-step-number">02</span>
    <h2>邀请 Bot 入群</h2>
    <ul>
      <li>QQ 官方 Bot 号：<code>3889004352</code>；</li>
      <li>显示名称：<strong>Amia_晓山瑞希</strong>；</li>
      <li>在目标群聊中选择“从群聊中选择联系人”，完成邀请；</li>
      <li>未加入用户交流群的邀请请求可能无法通过审核。</li>

  <section class="amia-step-card">
    <span class="amia-step-number">03</span>
    <h2>开启群消息权限</h2>
    <p>群主需要在机器人管理中为 Bot 开启“获取群内全部消息”权限。开启后，群成员才可以直接发送指令文本触发功能。</p>
  </section>

  <section class="amia-step-card">
    <span class="amia-step-number">04</span>
    <h2>发送第一条指令</h2>
    <p>完成权限配置后，可以发送 <code>帮助</code>、<code>个人信息</code>、<code>PJSK</code> 或 <code>经济帮助</code>。</p>
    <p>请直接发送指令文本，无需 @机器人。部分功能在 @机器人时可能无法正确识别。</p>
  </section>
</div>

</CommandExample>
