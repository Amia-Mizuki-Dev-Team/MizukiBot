## 官方帮助入口

**Amia_晓山瑞希** 是由 **Amia-Mizuki Dev Team** 维护的 QQ Bot 与插件集合。当前公开能力主要覆盖 PJSK、舞萌 DX、中二节奏、群聊管理与互动，并由身份绑定、权限、消息兼容和其他基础组件协同支撑。

组织中存在对应仓库或组件，不代表该能力已经在生产环境稳定开放。部分项目处于测试、迁移或独立维护状态；实际可用范围请以 [功能状态](/status)、对应功能页和最新公告为准。
