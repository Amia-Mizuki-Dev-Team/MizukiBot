## 官方帮助入口

**Amia_晓山瑞希** 是由 **Amia-Mizuki Dev Team** 维护的综合型 QQ Bot 与插件生态项目。当前公开能力覆盖 PJSK、舞萌 DX、中二节奏、群聊管理与互动，同时由协议桥接、身份绑定、权限与审计等基础组件协同支撑。

本站用于统一整理使用说明、功能状态、更新记录、项目生态和问题反馈入口。仓库或组件已经存在，并不代表对应能力已经作为稳定服务开放；生产状态以功能状态页和具体项目文档为准。
