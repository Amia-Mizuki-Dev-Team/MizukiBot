## 官方帮助入口

Amia_晓山瑞希，原名 **Mizuki Bot**，是由 Amia-Mizuki Dev Team 维护的综合型 QQ Bot，提供 PJSK 查询与车队辅助、舞萌 DX 成绩同步、B50 与 AP50、成绩分析、音游互动、经济系统及群聊管理功能。本站集中整理使用说明、功能文档、更新记录和问题反馈入口。
