# 问题反馈

为了缩短定位时间，请先阅读[常见问题与故障排查](/faq)，确认问题能够稳定复现，并尽量提供完整上下文。账号凭证、Token、登录二维码和其他敏感信息不得提交到公开表单。

## 故障反馈应包含

- 问题发生的日期和大致时间；
- 使用的群聊环境，以及是否为 QQ 官方 Bot；
- 实际发送的完整指令和参数；
- Bot 返回的文本、图片或错误提示；
- 从触发到出现问题的完整操作步骤；
- 问题是否可以重复出现；
- 必要的截图，但请先遮挡账号、Token、二维码等敏感内容。

## 功能建议应包含

- 需要解决的具体使用问题；
- 预期的操作流程和返回结果；
- 现有功能为何无法满足需求；
- 是否涉及管理员权限、用户数据或第三方服务。
