# 舞萌 DX 成绩同步风险说明

> 更新日期：2026 年 7 月 26 日

使用舞萌 DX 成绩同步功能前，请阅读本页并确认你理解其中的账号、凭证和第三方服务风险。继续使用相关功能，表示你已阅读并同意本说明。

## 1. 服务性质

1. 本功能由独立开发者提供，用于协助用户将《舞萌 DX》的游玩记录同步至指定的非官方查分平台。
2. 本功能与《舞萌 DX》的版权方、发行商、运营方及其关联公司不存在隶属、授权或合作关系，也不是官方服务的一部分。
3. 本功能依赖水鱼查分器、落雪咖啡屋等第三方接口。第三方服务的策略、可用性和数据格式可能随时变化。

## 2. 凭证与操作安全

1. 查分器 Token、OAuth 授权码、游戏登录二维码和其他登录凭证应视为敏感信息，不得转发给他人或提交到公开反馈渠道。
2. 导入成绩时使用的二维码文本可能具备短时登录权限。请在可信环境中操作，避免在公开或成员复杂的群聊中发送。
3. 因用户主动公开、错误转发或未妥善保管凭证而产生的账号风险，维护团队通常无法代为恢复或撤销。
4. 如怀疑凭证已经泄露，应立即前往对应平台撤销授权、更新 Token 或重新登录，并停止继续使用旧凭证。

## 3. 数据处理

1. 为维持自动查询功能，系统可能保存经过保护处理的游戏用户标识及必要的绑定关系。
2. 系统不会以提供本功能为目的长期保存登录二维码、明文 Token 或完整原始登录凭证。
3. 数据仅用于成绩同步、状态查询、故障排查和必要的安全审计，不用于出售或与功能无关的用途。
4. 用户可以通过[问题反馈](/feedback)申请查询、更正或删除相关绑定数据。处理前可能需要验证身份。

## 4. 工作模式与限制

- **仅同步**：获取成绩并上传至指定查分平台，必要时保存后续查询所需的用户标识；
- **同步后登出**：完成上传后尝试退出本次登录状态；
- 通过部分对手或公开接口取得的记录可能不包含 FC、FS 等完整状态；
- 后端维护、第三方接口限流或游戏服务调整都可能导致同步延迟、失败或数据不完整。

## 5. 固有风险

使用非官方工具访问游戏或第三方查分服务，可能面临以下风险：

- 游戏或查分平台调整接口后功能失效；
- 数据延迟、缺失、重复或显示不一致；
- 第三方平台限制访问、撤销授权或调整账号策略；
- 凭证泄露导致未授权访问；
- 游戏运营方依据其规则采取限制措施。

维护团队会在能力范围内采取合理的安全、维护和故障处理措施，但无法保证服务永久可用、数据绝对准确或任何第三方平台始终兼容。

## 6. 责任范围

在适用法律允许的范围内，维护团队不对由第三方服务中断、用户凭证泄露、违规操作、不可抗力或超出合理控制范围的事件造成的间接损失承担责任。对于依法不能排除或限制的责任，本说明不作排除。

发现安全问题时，请停止继续操作并通过[问题反馈](/feedback)联系维护团队，不要公开披露仍可利用的凭证或漏洞细节。
