维护、迁移和计划停机仍以[服务状态与公告](/service-announcements)为准。监控面板显示在线，也不代表所有插件和第三方数据源均可正常使用。

## 状态说明

- **已上线**：已经在正式 Bot 或公开服务中使用；
- **依赖上游**：模块本身已提供，但可用性受第三方接口、游戏数据或远程服务影响；
- **按需启用**：不会默认在所有群开启，需要管理员或用户主动配置；
- **测试中**：已有实现，仍在进行兼容性或生产验证；
- **独立服务**：与 Bot 主进程分开运行，维护安排可能不同。

“已上线”不代表永久无故障，也不构成持续可用性承诺。

## 数据边界与隐私

### 账号绑定数据

绑定关系只用于识别用户选择的游戏账号和默认查询对象。公开查询能力受具体模块、区服和用户隐私设置限制。引继码、密码、Token、OAuth 授权码及登录二维码不得提交到公开群聊或反馈表单。

### PJSK 上传数据

部分 Rating、组卡、详细资料和 MySekai 功能依赖用户主动上传的数据。上传数据是否有效、更新时间和支持范围由对应后端决定。Bot 无法替用户找回游戏账号。

### 舞萌 DX 数据

查询插件和成绩同步组件相互独立：

- 查询与分析模块读取已存在的查分数据并生成结果；
- 同步组件负责用户授权、排队、上传和会话清理；
- 一侧异常不一定代表另一侧同时异常。

### 群聊统计数据

基础发言统计与群聊活跃分析不是同一个模块。群聊活跃分析默认关闭，只有管理员在目标群主动开启后才开始记录匿名活动元数据。

公开的数据边界包括：

- 不保存消息正文；
- 不保存昵称；
- 不保存真实 QQ 号；
- 不保存平台虚拟用户 ID 或群 ID 明文；
- 不采集图片、语音和文件内容；
- 不采集私聊内容。

## 数据更新与延迟

不同模块的“更新”含义不同：

- **实时事件**：群消息、成员变动和部分群聊统计在事件到达后处理；
- **按请求查询**：歌曲、资料、榜线和成绩在用户发送指令时获取；
- **上传后更新**：suite、MySekai 和舞萌成绩需要用户先完成上传或同步；
- **队列处理**：舞萌成绩同步受维护窗口和排队人数影响；
- **持续监控**：Komari Agent 定期上报服务器运行指标；
- **部署更新**：插件代码与帮助文档需要经过测试和生产部署，不保证与仓库提交同时生效。

上游服务可能存在缓存、限流、维护或数据延迟，因此“游戏内已经变化”不等于 Bot 会立即显示新结果。

## 出现异常时先检查什么

<div class="mzk-table-wrapper">

| 现象 | 优先检查 |
| :--- | :--- |
| 监控面板显示服务器离线 | 主机、电源、网络、Agent 与监控面板连接 |
| 监控面板在线但 Bot 无响应 | Bot 进程、群消息权限、平台链路和插件日志 |
| 所有指令都无响应 | Bot 在线状态、群消息权限和平台链路 |
| 只有 PJSK 模块失败 | 区服、绑定、验证、上传数据和 PJSK 上游 |
| 只有舞萌查分失败 | 数据源绑定、默认路由和查分器状态 |
| 只有舞萌同步失败 | 维护窗口、队列、OAuth / Token 和异常会话 |
| 只有图片无法发送 | 图片生成、上传链路和 QQ 平台限制 |
| 群活数字不一致 | 统计模块、启用时间和统计口径 |
| 管理指令提示无权限 | 群角色、超级用户、身份映射和权限服务 |
| 文档与实际不一致 | Bot 内帮助、更新日志和当前生产部署 |

</div>

详细排查步骤见[常见问题与故障排查](/faq)。确认问题稳定存在后，再按[问题反馈](/feedback)要求提交完整信息。

## 面向开发者的状态

用户功能状态与仓库开发进度不是同一概念。插件可能已经有实现但仍待生产验证，也可能正在进行兼容更新而不影响现网旧版本。

公开项目职责与组件关系见[项目生态](/projects/)。仓库认领、测试状态和协作边界见[开发者招募与协作](/recruiting)。未明确标记为稳定发布的能力，不应视为正式服务承诺。
