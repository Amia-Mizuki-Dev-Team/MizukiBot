# Amia_晓山瑞希更新日志

本页只记录 Bot 本身的指令、插件、兼容性和问题修复。服务器维护、机房迁移、团队维护安排及 HongXing 关联产品调整统一记录在[服务状态与公告](/service-announcements)。

## 2026 年 8 月：Release010

MizukiBot Release010 已完成本轮生态代码收口、README 更新、自动化测试和正式仓库发布。本次覆盖 15 个生态仓库，共执行 194 项自动化测试，结果全部通过。

::: warning 当前发布边界
Release010 已完成代码发布与自动化验证，但真实 QQ / Gensokyo 环境手动验证尚未完成，生产启用仍待批准。以下内容表示 Release010 候选版本已经具备对应实现，不代表全部能力已经在正式 Bot 中启用。
:::

### 帮助系统

帮助系统现由 Amia 入口与 PicMenu Next 共同提供，支持：

- `help`、`帮助` 和 `@Bot help`；
- 图片首页、分类页面和功能详情页；
- 模糊搜索与拼音搜索；
- 插件功能自动聚合；
- Markdown、Keyboard、字符串及数组消息兼容；
- 图片或 Markdown 不可用时自动降级为中文文本。

### 欢迎与离群功能

欢迎和离群功能改用独立图库，并增加：

- 晓山瑞希风格随机中文文案；
- 正确 @ 新成员或离群成员；
- 静态图片 Markdown 显示；
- GIF 原生图片段与 Markdown 文案组合；
- 根据原图比例自动计算图片尺寸。

同时修复成员头像被误识别为欢迎表情包的问题。

### 经济系统快捷入口

打工和排行榜结果新增随机快捷入口，可跳转到：

- 每日任务；
- 股市；
- 我的持仓；
- 农场；
- 宠物；
- 副本；
- 我的卡牌；
- 经济帮助。

快捷入口不会包含抽卡、下注、购买、转账等直接改变资产的操作。

### Meme 表情包菜单

普通用户菜单重新整理为中文功能：

- 表情列表；
- 随机表情；
- 分类发送；
- 查看图片；
- 分类预览；
- 上传表情。

删除、溯源、锁定和屏蔽群等管理能力继续保留，但不显示在普通用户菜单中。

### PJSKHelp 与 Chunithm

PJSKHelp 继续保留本地帮助以及 Haruki、Sakura 网关，并新增 Chunithm 国服查询：

```text
chusearch <歌曲名>
chuinfo <歌曲ID>
chuchart <歌曲ID> [ex|ma|ult]
chu b30
```

当前仅支持国服，数据来源为 DivingFish。

### 舞萌 DX

`Amia-plugin-maimaidx` 本次更新包括：

- 保留 LXNS 与 DivingFish 双数据源；
- 优化 B50、曲库、进度和个人状态功能；
- 调整中文帮助按钮；
- 默认快捷按钮不再显示付费名片；
- 新增 `HX-MAI-*` 错误码；
- 失败时生成脱敏诊断附件；
- 不再向用户发送过长的异常信息；
- 同步 CN1.56 数字资源。

### 个人档案与身份系统

个人档案统一使用中文输出，并可聚合：

- QBind 身份；
- 活跃统计；
- 经济数据；
- Meme 数据；
- PJSK 数据。

单个数据模块缺失、超时或失败时，不会阻断整张个人档案生成。

Release010 继续使用字符串与 OpenID 身份体系。平台事件中的群会话 ID 不一定等于 QQ 客户端显示的群号，两者不会被视为同一概念。

### 错误提示与诊断

用户遇到错误时，将优先看到：

```text
错误码
简短原因
下一步建议
诊断附件（如有）
```

诊断内容不会包含 Token、数据库连接、完整 OpenID、本地绝对路径或完整异常栈。需要协助时，请保留诊断文件并加入开发者群 `1053964431`。

## 2026 年 7 月

### PJSK 功能与底层稳定性

- 将客户端代理引擎从 `websockets` 升级为 `aiohttp`，缓解 Windows 和双栈网络环境下频繁出现的远程连接拒绝问题；
- 补全 NapCat / OneBot V11 握手请求头，并处理登录信息与生命周期 API 回调，降低被后端防火墙误判为非法客户端的概率；
- 修复存活心跳包处理逻辑错误导致的代理与客户端循环断线重连；
- 重构双端指令池，将指令划分为专有指令与共用指令，修复“补票”“倍率”等特殊指令及工具箱指令被代理误拦截的问题；
- 优化外链清洗规则，正确放行 `[CQ:image,file=...]` 等内部图片链接，避免误删游戏截图与资源；
- 新增指定群聊免斜杠触发，并使用 `auto_slash_groups.json` 保存启用状态；
- 免斜杠配置仅限 Bot 超级管理员通过 `免斜杠配置 群号` 或 `免斜杠取消 群号` 热更新，并在帮助菜单中增加风险提示；
- 重构帮助菜单，扩充帮助按钮，将笼统描述替换为可直接复制的指令示例；
- 修复帮助菜单中工具箱地址无法点击的问题，适配标准 Markdown 超链接格式。

### 经济榜与经济系统

#### 图像渲染

- 修复打工结算图片中收益正负号拼接错误，负收益不再显示为 `+-2 PC`。

#### 数据库与业务逻辑

- 修复排行榜 SQL 变量转义崩溃，将 `DATE_FORMAT` 中的百分号正确转义，避免 `aiomysql` 格式化变量误判；
- 为发红包、抢红包和商城购买事务补充 `economy_logs` 账单流水；
- 为红包账单加入 6 位字母数字混合序列号，便于查账、防重和溯源；
- 适配网页排行榜字段并自动计算排名序号。

#### 接口与交互

- 将 `safe_execute` 并发超时时间从 10 秒调整为 45 秒，降低高并发或图片生成时的误报警概率；
- 通过 FastAPI 挂载 `/economy/rank` GET 接口并配置 CORS，使 `list.mizuki.top` 可以读取实时排行榜；
- 新增商城提货指令 `结算订单`，别名为 `购买`，用于承接网页商城生成的文本命令；
- 增强 PK 目标识别，支持回复对象和消息内 at 节点，并过滤无效目标；
- 区分 QQ 官方 Bot 的 Markdown 与按钮流程和普通 Bot 的纯文本降级流程；
- 修复 `经济帮助` 菜单硬编码玩家昵称的问题，改为动态读取当前触发者昵称。

### 白名单与群聊鉴权

- 将授权成功缓存设为 10 分钟，失败状态缓存缩短为 30 秒，减少群管授权后的恢复等待时间；
- 改为遍历群成员列表提取 `role == "owner"` 的群主身份，并自动修复旧数据中的无效群主记录；
- 增加全局拦截钩子，阻断未授权群聊消息进入其他插件；
- 拦截提示仅向群主或管理员返回，并设置 5 分钟冷却；
- 管理面板弃用旧版 Tortoise ORM 查询方式，改用兼容 `nonebot-plugin-orm` 的异步 SQLAlchemy 查询；
- 管理面板使用树状明细展示群名、群主和邀请人等信息，优化移动端可读性；
- 增加状态标识，区分超级管理员特批与开发群授权放行。
